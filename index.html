Converting

Slots

Drop several sounds anywhere on the page and they go to the slots their names point to (kick, snare, hh…), the rest into free slots. Drop on a slot to put a sound exactly there.

On the card

Put the kit folder in the card's samples folder, or a folder inside it such as samples/Performer Drums. The NT looks for new samples when it starts, so restart it after adding a kit.

What gets written

WAV files at the sound's own resolution (24-bit sources stay 24-bit, 16-bit stay 16-bit), named 1KIK-012.wav, 5SNR-012.wav and so on, so each lands on its voice. Pitch, decay, drive and the rest are set on the NT and saved in its presets.

Files it reads

WAV and AIFF in any browser; MP3, FLAC, Ogg and others where the browser can decode them. "Save to card" needs Chrome or Edge; other browsers download a zip instead.

The Performer's drum patterns are in LIBRARY/DRUMS.LIB on its card. Pattern N plays kit N: the kit track sends program change N when it starts. New and imported patterns go at the end, so the numbers of the others never change.
