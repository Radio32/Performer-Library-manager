Conducting Performer · phrase libraries

Library Manager

Open the libraries from the Performer's card (LIBRARY/BASS.LIB, MELODY.LIB, DRUMS.LIB, PROGS.LIB) to preview, sort and tidy them. Open a second library in the right-hand pane to copy between the two. Nothing is written until you save.

Kits Patterns Library Controller

One library of each kind per card. The Performer reads one file per kind: BASS.LIB, MELODY.LIB, DRUMS.LIB and PROGS.LIB in its LIBRARY folder. Two libraries of the same kind can't be on the same card.

  • Open… a file from the card to change that library: Save writes your changes over the same file.
  • To bring phrases from another library file (a backup, a friend's), open it in the second pane and copy them across into the card's library. Saving the other file to the card under the same name would replace the card's library, not add to it.
Keys and tips

Select: click a row; SHIFT + click a range; ⌘ (Ctrl) + click to add or remove one; click a category's name for all of it; ⌘A for everything (in the pane you clicked last).

Edit: ⌘C copy · ⌘X cut · ⌘V paste after the last selected row (into its category; with nothing selected, at the end) · ⌘D duplicate · ⌫ delete · ⌥↑ ⌥↓ move · ↑ ↓ (SHIFT) the selection · ⏎ or double-click rename · ⌘Z undo · SHIFT ⌘Z redo · SPACE play / stop.

Categories (the Performer's STYLE on S1): Move to… puts the selected phrases into another category, or a new one. The Categories list in each pane adds, renames, deletes and reorders them; deleting one moves its phrases to another category or deletes them too. Renaming a category to the name of another joins the two. A new category is kept until you save; one that has no phrases by then is left out (a library file only has categories with phrases).

Between libraries: bass lines and melodies paste into each other's library; drum patterns and progressions only into their own kind.

On the Performer: the library is browsed category by category, so saving puts each category's phrases together (where it first appears); up to 16 categories. Pattern and drum chain entries remember the number of the phrase they were loaded from (LIB 012), and SAVE on S1 writes an edited pattern back to that number: after phrases are moved or deleted, load an entry from the library again before saving it back.
